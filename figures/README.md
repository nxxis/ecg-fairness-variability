# figures/

This folder mirrors `{PROJECT_DIR}/figures/` from the notebook (`SAVE_DIR` in Block 15/22) —
every figure the pipeline produces by default, each saved as a vector `.pdf` (camera-ready) and a
raster `.png` preview. Generated by the notebook, not hand-edited.

**Only one of these appears in the paper body: `Figure3_Stability`, which is the paper's Fig. 2**
("Predictive Performance vs. Fairness Stability (Large 1D-CNN)" — macro-AUROC held near-constant
across ten seeds while Older Female MI FNR swings from 27.06% to 44.95%). The paper's Fig. 1 is a
separate schematic of the overall study pipeline (PTB-XL → preprocessing → four variants × ten
seeds → the four evaluation axes); it is a hand-authored diagram, not produced by this notebook,
and is not present in this folder. The paper's evidence is otherwise reported entirely in Tables
I–XVI and the Appendices; every other file below is supplementary notebook output, useful for
exploring the same analyses visually, but not embedded in or referenced by the manuscript.

| File | Contents | In paper? |
|---|---|---|
| `Figure1_MI_FNR` | MI FNR by demographic subgroup and model, seed 42 (the data underlying Table IV) | No |
| `Figure3_Stability` | Macro-AUROC vs. Older-Female MI FNR across 10 seeds, Large 1D-CNN | **Yes — paper Fig. 2** |
| `Figure6_Convergence` | Validation-loss convergence, all four models, seed 42 | No |
| `Figure7_Reliability` | Reliability diagrams, MI and STTC | No |
| `Figure8_External_STTC_FNR` | STTC FNR by subgroup and model, Georgia external validation (Table XI) | No |
| `Figure9_CrossDomain_Stability` | FNR CV: PTB-XL (MI) vs. Georgia (STTC) (Table XII) | No |
| `Figure10_Pareto_Frontier` | Macro-AUROC vs. MI FNR disparity, all 40 runs (descriptive association, not a selection criterion) | No |
| `Figure11_Threshold_Sensitivity` | FNR CV under fixed vs. validation-calibrated threshold (Table XIII) | No |

A former `Figure2` (a radar/polar chart of older-female FNR) was removed from the pipeline as a
harder-to-read duplicate of `Figure1_MI_FNR`'s grouped bar chart; the notebook documents this
inline where the figure numbering skips it. `Figure4_GradCAM` and `Figure5_Robustness` are only
generated when the notebook's `RUN_OPTIONAL_DIAGNOSTICS` flag (Block 13/14) is set to `True` — it
defaults to `False`, so those files are not present here, and the analyses they'd show (Grad-CAM
clinical-alignment scoring, robustness to clinical signal artifacts) are not part of this study's
central fairness-instability analysis or its reported tables.

## Where the paper's numeric tables come from

The notebook does not export the paper's tables (I–XVI) to CSV — every table is printed directly
to the Colab cell output by functions such as `print_fairness_report`, `print_equalized_odds_report`,
`print_results_table`, and `run_delong_comparisons` (Blocks 9, 11, 12, 19–21), plus the lettered
appendix blocks (A–I) for the multi-seed disparity, matched-comparison, threshold-policy, and
validation-selection tables. To get a table's exact numbers, re-run the corresponding block in
Colab and read them from the cell output, or check the block-to-table map in
[`../docs/reproducibility.md`](../docs/reproducibility.md).
